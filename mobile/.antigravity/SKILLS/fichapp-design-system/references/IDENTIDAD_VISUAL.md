# Identidad visual de FichApp

## Posicionamiento

FichApp combina tecnología y deporte. Debe sentirse como un producto digital moderno,
organizado y confiable, con energía deportiva moderada. No debe parecer una aplicación de
resultados, apuestas o seguimiento de partidos.

Referencias de sensibilidad visual:
- Notion: claridad, organización y sobriedad.
- Figma: cuidado de producto y atención al detalle.
- Rial: cercanía y confianza dentro del contexto latinoamericano.

Son referencias de atributos, no instrucciones para copiar interfaces, componentes o marcas.

## Personalidad

- Moderna, pero no futurista.
- Deportiva, pero no estridente.
- Profesional, pero no fría.
- Cercana, pero no infantil.
- Clara y funcional antes que ornamental.

## Decisiones acordadas

| Atributo | Dirección |
|---|---|
| Personalidad | Tecnología + deporte |
| Tema principal | Claro |
| Paleta | Azul petróleo + verde lima |
| Verde lima | Presencia moderada |
| Densidad | Equilibrada |
| Tipografía | Inter |
| Geometría | Moderadamente redondeada |
| Navegación | Híbrida y adaptativa por rol/permisos |
| Plataforma | Mobile-first |
| Listados | Adaptativos según contenido y dispositivo |
| Iconografía | Preferencia por Lucide, sujeta a compatibilidad |
| Sombras | Mínimas |
| Gradientes | No por defecto |
| Tarjetas | Uso selectivo, no universal |

## Principio visual

El azul petróleo aporta estructura y confianza. El verde lima aporta energía y reconocimiento
de marca, sin dominar todas las pantallas. Los fondos claros y neutros permiten que los datos,
las personas y las operaciones sean protagonistas.

## Dos contextos, una identidad

### Administración
Debe priorizar legibilidad, jerarquía, datos, filtros, formularios, importes y acciones
precisas. Puede ser más densa, pero no confusa.

### Deporte y operación en cancha
Debe priorizar rapidez, reconocimiento de personas, controles táctiles y lectura inmediata.
La interfaz debe reducir pasos y distracciones.

### Familias y representantes
Debe priorizar comprensión, confianza, relación entre representantes y jugadores, y claridad
de pagos y avisos.

Los tres contextos comparten colores, tipografía, iconos, componentes y reglas de interacción.
